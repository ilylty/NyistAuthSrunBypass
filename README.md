# NyistAuthSrunBypass

南阳理工学院 校园网无感登陆


## 安装方法
### 执行下面的命令

   ```bash
   cd NyistAuthSrunBypass
   pip install -r requirement.txt
   ```
## 配置账号密码
### 在enc.py中修改账号和密码
在**line_9**和**line_10**配置账号密码
```
username = ''
password = ''
```

## 运行
   ```bash
   python enc.py
   ```
